SmartSpend AI

AI-Powered Invoice Checking & Risk Scoring System

SmartSpend AI automates invoice checking using AI, ASP.NET Core Web API, and SQL Server.

Current Features-
PDF invoice upload & text extraction
AI-based invoice data extraction
Invoice data validation
Duplicate invoice detection
High-amount detection
Tax mismatch detection
Explainable risk scoring
Invoice CRUD APIs
SQL Server + Entity Framework Core
Swagger API testing

Workflow-
PDF Invoice
    ↓
PDF Extraction
    ↓
AI Extraction
    ↓
Validation
    ↓
Business Checks
    ↓
Risk Score
    ↓
SQL Server
    ↓
Web API
Tech Stack-

C# | ASP.NET Core | Entity Framework Core | SQL Server | Groq AI | Swagger | GitHub

Current Status-
